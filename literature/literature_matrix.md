## Instructions

- **Scope:** For **Empirical Evidence**, use only Defensiveness and Interconnection (only the named subsection if one is given); for **Methodological**, use Beta and/or Partial Correlation as requested; for **Further Evidence**, use only that section. Expand the source set only on request.
- **Reading:** Use this matrix to select the local PDFs, then verify every statement in the full text before answering; the matrix is a navigation aid, not a substitute for the PDF.
- **Citation:** Cite the PDF in `literature/pdf/` with its printed year, printed page and table/figure number; add the PDF page when it differs. For journals with article numbers (e.g., *Physical Review E*), cite the page within the article (e.g., p. 3) and give the article number in the reference list.
- **Columns:** **LLM Findings** contains findings extracted by the LLM from the full-text PDF: • marks a main finding in the order Tech / Utilities; **Extra:** introduces ▪ points with sample, period, method, significance, market phases, and limitations or errors. **Human Review** records the researcher's check: ✅ Verified = checked against the PDF and correct; ✏️ Corrected: = LLM entry was wrong, followed by the corrected entry with the changed part in bold; empty = not yet reviewed. Rows with empty Paper and PDF cells continue the paper above.
- **File naming:** `Author_Author_Year_Short_Title.pdf` (`et_al` for more than three authors, ASCII spelling, version suffix if needed).

|  |  | • Time-series test: the market model (Eq. 3) plus an intercept gives the regression R_jt = α_j + β_j R_Mt + e_jt on excess returns; the traditional CAPM implies α_j = 0 (Black, Jensen & Scholes, 1972, pp. 6–7, Eqs. 3, 6; PDF pp. 8–9). | ✅ Verified |
|  |  | • Grouping: Eq. 6 is estimated on portfolios instead of single securities, so the intercept's standard error reflects cross-sectional dependence of residuals (Black, Jensen & Scholes, 1972, pp. 8–9; PDF pp. 10–11). |  |
|  |  | • Ranking: each January 1931–1965, NYSE securities with ≥ 24 monthly returns are ranked by β from the preceding five years and sorted into ten portfolios; portfolio returns are computed for the next 12 months, avoiding selection bias in β (Black, Jensen & Scholes, 1972, pp. 9, 11–12; PDF pp. 11, 13–14). |  |

| **Kenett, D. Y., Huang, X., Vodenska, I., Havlin, S., & Stanley, H. E. (2014).** *Partial correlation analysis: Applications for financial markets* (arXiv:1402.1405v1) [Preprint]. arXiv. <https://arxiv.org/abs/1402.1405> | [Kenett_et_al_2014_Partial_Correlation_Analysis_Preprint.pdf](<pdf/Kenett_et_al_2014_Partial_Correlation_Analysis_Preprint.pdf>) | • Partial correlation ρ(X, Y : M) is the Pearson correlation of the residuals of X and Y after both are regressed on the market index M; it removes the common driving factors represented by the index (Kenett et al., 2014, p. 4). | ✅ Verified |
|  |  | • Equivalent formula from raw correlations: ρ(X, Y : M) = [ρ(X, Y) − ρ(X, M)ρ(Y, M)] / √([1 − ρ²(X, M)][1 − ρ²(Y, M)]) (Kenett et al., 2014, p. 4, Eq. 3). |  |
|  |  | • Raw correlation is the Pearson correlation of daily log returns r_i(t) = log[P_i(t)/P_i(t − 1)] (Kenett et al., 2014, p. 4, Eqs. 1–2). |  |
|  |  | • Conditioning on the S&P 500 lowers the correlation of every stock pair; the index influence on pairwise correlations is always positive (Kenett et al., 2014, pp. 4–5, Fig. 1a). |  |
|  |  | • Significance: Fisher z = ½ ln[(1 + ρ)/(1 − ρ)] is approximately N(·, 1/√(N − 3)), also for partial correlations (Kenett et al., 2014, p. 6, Eqs. 7–8). |  |
|  |  | • Tech–Utilities partial correlation is not reported; sector-influence correlations show technology close to communications and utilities anti-correlated with consumer discretionary (Kenett et al., 2014, pp. 12–13, Fig. 7). |  |
|  |  | **Extra:** |  |
|  |  | ▪ Data: daily adjusted closing prices from Thomson Reuters Datastream, Jan. 2000–Dec. 2010; S&P 500 (403 stocks after filtering), FTSE 350, Nikkei 500, BSE 200 (Kenett et al., 2014, p. 3, Table 1). |  |
|  |  | ▪ Stock level, not sector portfolios; GICS sectors only aggregate the influence measures (Kenett et al., 2014, pp. 10–11, Eqs. 12–13). |  |
|  |  | ▪ Regression method (e.g., OLS, intercept) is not specified (Kenett et al., 2014, p. 4). |  |
|  |  | ▪ Fisher test assumes bivariate normality and independent observations; valid when ρ is not too large and N not too small (Kenett et al., 2014, p. 6). |  |
|  |  | ▪ Empirical shuffling test preferred; two-tailed 2% level (z > 1.6449) used throughout (Kenett et al., 2014, pp. 6–8, Table 2). |  |
|  |  | ▪ U.S. market structure changes after the dot-com crisis (Q4 2000–Q4 2001) and the credit crunch (Q4 2007–Q4 2008) (Kenett et al., 2014, pp. 8–9, Fig. 3). |  |
|  |  | ▪ Weight N − 3 also for partial correlations, citing Fisher (1924); the proposal uses N − 4 (Kenett et al., 2014, p. 6, Eq. 8). |  |
