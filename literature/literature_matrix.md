## Instructions

- **Scope:** For **Empirical Evidence**, use only Defensiveness and Interconnection (only the named subsection if one is given); for **Methodological**, use Beta and/or Partial Correlation as requested; for **Further Evidence**, use only that section. Expand the source set only on request.
- **Reading:** Use this matrix to select the local PDFs, then verify every statement in the full text before answering; the matrix is a navigation aid, not a substitute for the PDF.
- **Citation:** Cite the PDF in `literature/pdf/` with its printed year, printed page and table/figure number; add the PDF page when it differs. For journals with article numbers (e.g., *Physical Review E*), cite the page within the article (e.g., p. 3) and give the article number in the reference list.
- **Columns:** **LLM Findings** contains findings extracted by the LLM from the full-text PDF: • marks a main finding in the order Tech / Utilities; **Extra:** introduces ▪ points with sample, period, method, significance, market phases, and limitations or errors. **Human Review** records the researcher's check: ✅ Verified = checked against the PDF and correct; ✏️ Corrected: = LLM entry was wrong, followed by the corrected entry with the changed part in bold; empty = not yet reviewed. Rows with empty Paper and PDF cells continue the paper above.
- **File naming:** `Author_Author_Year_Short_Title.pdf` (`et_al` for more than three authors, ASCII spelling, version suffix if needed).
